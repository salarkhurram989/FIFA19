FIFA19 CrazyGames upload package

Upload the CONTENTS of this folder directly to CrazyGames.
Do NOT upload this folder as a ZIP.

Required files:
- index.html
- game.js
- style.css

The game uses Three.js from jsDelivr. For a completely offline package, download/pin Three.js locally and replace the import in game.js with ./vendor/three.module.js.
